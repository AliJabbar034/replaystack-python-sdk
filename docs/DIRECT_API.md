# ReplayStack Direct API Usage from Python

You can skip the SDK and POST events directly to the ingest API. This is useful for one-off scripts, smoke tests, or environments where you can't add a new dependency.

```python
import requests

requests.post(
    "https://api.replaystack.co/api/v1/ingest/events",
    headers={
        "Content-Type": "application/json",
        # Canonical TraceReplay header:
        "x-tracereplay-api-key": "rs_live_xxx",
        # Legacy duplicate alias (kept for backward compatibility):
        "x-replaystack-api-key": "rs_live_xxx",
        "x-replaystack-sdk": "direct",
    },
    json={
        "eventType": "custom",
        "endpoint": "nightly-job",
        "status": "success",
        "responsePayload": {"message": "Done"},
    },
    timeout=2,
)
```

## Field Reference

All keys are camelCase. The SDK does this mapping for you (`event_type` → `eventType`, `request_payload` → `requestPayload`, etc.).

| Field | Type | Notes |
|---|---|---|
| `traceId` | `string` | Optional. Generated by the SDK if missing. |
| `eventType` | `'api' \| 'queue' \| 'webhook' \| 'custom' \| 'cron'` | Required. |
| `status` | `'success' \| 'failed' \| 'warning' \| 'pending'` | Required. |
| `method`, `endpoint`, `requestUrl` | `string` | Endpoint normalized to a path; `requestUrl` is the absolute URL. |
| `authMode` | `'bearer' \| 'basic' \| 'api_key' \| 'cookie' \| 'other' \| 'none'` | Detected before masking. Optional. |
| `authScheme` | `string` | Original `Authorization` scheme name (e.g. `Bearer`). |
| `requestHeaders`, `responseHeaders` | `object` | After masking. |
| `requestPayload`, `responsePayload` | `any` | After masking + truncation. |
| `statusCode` | `int` |  |
| `executionTimeMs` | `int` |  |
| `errorName`, `errorMessage`, `stackTrace` | `string` |  |
| `stackFrames` | `array` | `{ functionName, fileName, lineNumber, columnNumber, raw }` |
| `breadcrumbs` | `array` | `{ message, category, level, metadata, timestamp }` |
| `serviceName`, `environment`, `appVersion`, `commitHash` | `string` |  |
| `sourceIp`, `userAgent` | `string` |  |
| `logs`, `metadata` | `array`/`object` | Free-form structured data. |
